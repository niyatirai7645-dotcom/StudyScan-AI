# 📚 StudyScan AI

## AI-Powered Classroom Notes Assistant

### 📌 Project Overview

StudyScan AI is an AI-powered educational assistant developed to support **SDG 4 – Quality Education**.

Teachers often share classroom notes as photographs through messaging platforms. These images are difficult to organize, search, revise, or directly use with AI tools.

StudyScan AI solves this problem by converting classroom note images into structured and personalized learning resources using Google's Gemini AI.

---

## 🚀 Features

* 📷 Upload classroom note images
* 📖 Generate Clean Notes
* 📝 Generate Summary
* ❓ Generate Quiz
* 🧠 Generate Flashcards
* 🎯 Generate Exam Questions
* 🌐 English and Hindi support
* 📥 Download generated study material

---

## 🛠️ Technology Stack

* Python
* Streamlit
* Google Gemini API
* Pillow
* Python Dotenv

---

## 🎯 Sustainable Development Goal

**SDG 4 – Quality Education**

This project improves learning accessibility by converting unstructured classroom notes into structured study material for students.

---

## 💡 Problem Statement

Students receive classroom notes as images through WhatsApp or other platforms.

These images cannot be directly used for effective revision or uploaded easily to AI tools.

StudyScan AI transforms those images into organized learning resources.
